Solidtime for ClickUp

Start a Solidtime timer from any ClickUp task. Entries are named Task title | #taskid.

Unofficial community extension, not affiliated with Solidtime or ClickUp. Provided as is, without warranty: please check your tracked time.

1. Connect

Self-hosted and Create API Token fails? An admin has to enable API tokens once on the server: docker compose exec scheduler php artisan passport:client --personal --name="API" (press Enter to accept the default users provider).

2. Tracking

Projects

Uses the Solidtime project whose name appears in the ClickUp List name (or, failing that, the Space name), e.g. List example.com – Website → project example.com. Whole words only; the longest name wins.

Manual mappings

Optional. These take priority over automatic matching: a List mapping wins over a Space mapping. Anything unmatched uses the default project. Names are matched case-insensitively.

Type ClickUp name Solidtime project
